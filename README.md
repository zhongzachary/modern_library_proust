# Modern Library 6-Volume _In Search of Lost Time_ Synopses & Guide

Visit the interactive database here: [Modern Library Proust](https://zhongzachary.github.io/modern_library_proust/)

This repository is intended as a digital version of Modern Library's Synopses of _In Search of Lost Time_ by Marcel Proust and Terence Kilmartin's _A Guide to Proust_.

It is meant as a more easily searchable way to review the companion materials for readers of the _Modern Library In Search of Lost Time_. This is an unofficial, noncommercial reader aid intended for personal study and reference by readers of the Modern Library edition. All rights in the original materials remain with their respective copyright holders.

Page numbers are for the 2003 Modern Library 6-Volume Paperback Edition.

Please raise issues or create a pull request if you find any typos or incorrect formatting in the texts.

If you are a copyright holder or authorized representative and would prefer that this material not be available here, please contact me through GitHub. I will promptly remove the affected material upon request.
